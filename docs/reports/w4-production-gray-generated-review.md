1. \(v(0)=0\)；
2. \(0<z<\ell\) 时 \(v>0\)；
3. \(z\to\ell\) 时 \(v\to0\)；
4. 由速度连续可知速度先增后减，后段仍向下运动但加速度向上，故选 E。
