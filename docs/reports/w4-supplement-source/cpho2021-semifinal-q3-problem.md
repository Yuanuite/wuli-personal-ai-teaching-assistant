# 第38届全国竞赛复赛第3题：超球连续三次碰撞

一个质量为 $m$、半径为 $r$ 的均质超球在上、下两个固定平行硬板之间运动，与两板
依次碰撞三次后几乎返回原处；第一次碰撞下板，第二次碰撞上板，第三次再碰下板。
取 $x$ 轴水平向右、$y$ 轴竖直向下，$z$ 轴正方向按
右手螺旋确定。开始时球心速度的水平分量为 $v_{0x}>0$，$z$ 方向速度分量为零；
球绕平行于 $z$ 轴的轴以正角速度 $\omega_{0z}$ 转动，且
$0<\omega_{0z}<v_{0x}/r$。忽略重力。

超球与硬板的反跳可视为完全弹性；碰撞期间接触点无滑动，切向形变与法向形变彼此
无关并各自储存、释放弹性能。球的转动惯量为

$$
J=\frac25mr^2.
$$

依次求第 1、2、3 次碰撞后球心速度的水平分量
$v_{1x},v_{2x},v_{3x}$ 和角速度
$\omega_{1z},\omega_{2z},\omega_{3z}$。

> 来源：第38届（2021年）全国中学生物理竞赛复赛第3题官方题目；
> 仅统一了角速度正号的文字表述，公式条件保持不变。
