# APhO 2019 Q3-A3：接触点速度的竖直分量

一个刚体陀螺始终在点 \(A\) 与静止的水平地面接触。设质心 \(C\) 的位置向量为
\(\mathbf s\)，从质心指向接触点的向量为 \(\mathbf a=\overrightarrow{CA}\)，
\(\hat{\mathbf z}\) 为竖直向上的固定单位向量，刚体角速度为 \(\boldsymbol\omega\)。

接触约束为

\[
(\mathbf s+\mathbf a)\cdot\hat{\mathbf z}=0.
\]

接触点速度满足刚体运动学关系

\[
\mathbf v_A=\dot{\mathbf s}+\boldsymbol\omega\times\mathbf a.
\]

证明接触点 \(A\) 的速度没有竖直分量，即

\[
\mathbf v_A\cdot\hat{\mathbf z}=0.
\]
