# IPhO 2021 T1-A1：油水两侧的板上合力

一个大型水槽处于重力加速度为 $g$ 的匀强重力场中。两块相互平行的竖直长方形板
插入水中，每块板浸入水中的深度为 $h$，沿垂直纸面方向的宽度为 $w$。水的密度为
$\rho_0$。

把密度为 $\rho_{\mathrm{oil}}<\rho_0$ 的油倒入两板之间，直到油的最下方恰好达到
两板下边缘；两板之间不再有水，且油不会溢出。忽略表面张力与流体混合。

求右板所受合力的水平分量 $F_x$ 的大小和方向。规定水平向右为 $x$ 轴正方向。
