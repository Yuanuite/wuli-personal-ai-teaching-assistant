# APhO 2019 Q3-A8：翻转陀螺五阶段能量变化

一个翻转陀螺在粗糙水平地面上运动。初始时仅给陀螺很大的自转角速度，没有平移
冲量。接触点发生滑动，滑动摩擦力始终与接触点相对地面的速度方向相反。运动分为：

陀螺的质心 $C$ 沿对称轴偏离几何中心 $O$ 的距离为 $\alpha R$，
$0<\alpha<1$。陀螺柄与竖直向上的夹角为 $\theta$，在翻转过程中由接近 $0$
增大到接近 $\pi$；柄触地前质心高度满足
$h_C=R(1-\alpha\cos\theta)$。

1. 阶段 I：刚开始转动，陀螺柄近似竖直向上；
2. 阶段 II：陀螺逐渐倾斜；
3. 阶段 III：陀螺柄第一次接触地面；
4. 阶段 IV：陀螺翻转后以柄为支撑继续旋转；
5. 阶段 V：陀螺最终静止在柄上。

定性描述从阶段 I 到 V 的下列能量随时间的变化，并说明关键阶段特征：

- 总机械能 $E_T$；
- 重力势能 $U_G$；
- 质心平动动能 $K_T$；
- 绕质心转动动能 $K_R$。

不要求按比例作图，但必须说明单调性、初末状态及阶段 IV 附近的特征。
