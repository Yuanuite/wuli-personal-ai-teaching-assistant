# CPhO 2021 Flash 纯物理过程分析消融测试

结论：把任务限制为物理过程分析后，Flash 的目标级严格正确率由完整核心求解样本的 2/27 提高到 7/27，但整题严格正确仍为 0/8。因此公式推导不是首要瓶颈；Flash 在参考系、方向、阶段切换、稳定性、守恒系统边界和过程分支方面仍不可靠。

## 隔离条件

- 使用 CPhO 2021 全年 8 道题及已有 MiMo 视觉事实。
- Flash 看不到标准答案。
- 禁止输出最终答案、代数推导和数值计算。
- 只输出系统边界、状态、阶段、相互作用、方向、定律、约束和逐目标决定性物理判断。
- 候选全部冻结后，才在本地按照官方标准答案审核。
- 报告不包含题目、候选或标准答案正文。

## 结果

| 指标 | 结果 |
|---|---:|
| 结构成功 | 8/8 |
| 90 秒内完成 | 8/8 |
| Flash 中位耗时 | 19.622 s |
| Flash 最大耗时 | 26.198 s |
| 整题物理过程严格正确 | 0/8 |
| 子目标物理过程严格正确 | 7/27（25.93%） |
| 完整核心求解的子目标基线 | 2/27（7.41%） |

过程拆分产生了真实提升，但不足以单独解决正确性问题。结构成功率不能替代物理正确率。

## 主要剩余故障

1. 没有真正消解参考系、法线、接触点和摩擦方向，只把它们写入“风险检查”。
2. 能列出相关定律，但没有决定哪条定律在当前阶段成立。
3. 对稳定性、临界条件和场的空间分区不给明确判断。
4. 使用守恒定律时没有正确划定系统边界和外力矩。
5. 生成题目未给出的过程分支，导致后续推导被错误分段。

## 判断

当前瓶颈可以定位为“决定性物理状态判别”，而不是公式书写能力。下一步不应继续扩大 Physical Kernel；应把其中最危险的判断改造成必须给出唯一结论且能被确定性检查的少量状态断言，例如方向、区域、守恒系统、阶段切换和边界条件。无法唯一判断时必须返回 `unsupported`，不能把不确定性藏在 `risk_checks` 中后继续生成答案。
