# CPhO 2021 Flash 原子物理断言消融测试

结论：原子断言提高了失败关闭能力，却没有提高物理真值准确率。强迫 Flash 对每个方向、阶段、守恒边界和能量流给出唯一判断，会把部分不确定性转化为自信的错误模型。

## 契约

- 每个断言只允许一个物理判断。
- 必须给出判断、依据、检查类型和具体 falsifier。
- 禁止最终答案、完整推导和数值计算。
- 禁止“可能、待判断、需确认”等含糊措辞。
- 不能判断时应返回 `unsupported`。
- 不允许重试；标准答案只在候选冻结后本地审核。

## 结果

| 指标 | 结果 |
|---|---:|
| 结构成功 | 4/8 |
| 门禁拒绝 | 4/8 |
| 成功调用中位耗时 | 11.526 s |
| 成功调用最大耗时 | 11.754 s |
| 整题严格正确 | 0/8 |
| 全年目标严格正确 | 2/27（7.41%） |
| 有合法候选的目标严格正确 | 2/13（15.38%） |

对比：完整核心求解为 2/27，宽泛 Physical Kernel 为 7/27，原子断言又回落到 2/27。

## 解释

原子化本身只改善了可审计性：错误现在更容易定位，含糊输出能够直接拒绝。但它不提供物理真值。Flash 仍会明确选择错误的曲面类别、碰撞系统边界、自由轮摩擦方向或能量流，并为这些错误判断生成看似合理的依据和 falsifier。

因此，“原子任务保障模型不会出错”这个观念需要修正为：

> 原子任务只能让错误更局部、更易检出、更容易失败关闭；没有外部真值或可靠验证器时，它不能保证物理判断正确。

当前不应把原子断言接入生产求解链。若保留，应仅作为审计 sidecar，并要求每个断言经过标准答案证书或真正独立的物理验证器后，才允许影响最终答案。
