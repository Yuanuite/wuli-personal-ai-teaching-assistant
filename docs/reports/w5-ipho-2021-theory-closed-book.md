# W5：2021 IPhO 理论卷隔离作答报告

## 结论

2021 年 IPhO 三道理论题完成了“题目与答案隔离 → 完整作答 → 候选冻结 → 解答解锁
→ 独立逐小问阅卷”的全卷测试。实验题 E1、E2 按用户要求排除。

最终结果：

- T1、T2、T3 均为 `10.0/10.0`；
- 36/36 个官方小问均判为 `full-credit`；
- 无 `partial-credit`、`zero` 或 `needs-review`；
- 候选冻结前没有向求解器披露官方解答；
- 求解器和阅卷器使用不同运行时/模型，阅卷器只在候选冻结后读取官方解答。

该结果证明当前系统在这套公开竞赛卷上生成了与官方解答逐小问一致的答案，不等同于
“对任意新物理题均可形式证明正确”。它是新的整卷观察证据，不替代教师门禁，也不用于
修改已经通过的 W4 生产路由阈值。

精确加总：

- 有效作答 Agent 时间：265.416 s；
- 首轮脚手架失败 Agent 时间：281.260 s；
- 独立阅卷 Agent 时间：195.591 s；
- 全部已记录 Agent 时间：742.267 s；

三题并行运行，所以 Agent 时间之和不是批次实际等待时间。由秒级开始/结束时间计算，有效
作答批次约 101 s，独立阅卷批次约 101 s。Codex 求解 provider 没有返回 token 计数，因此
求解 token 明确记为 `unavailable`；答案字符数只是传输规模观测，不作为 token 估算。

## 失败记录

首轮三题都完成了结构化生成，但评测脚手架错误地同时把
`candidate-answer.json` 放入允许和拒绝范围，Gateway 因
`unauthorized_change` 拒绝提升。该次没有形成候选、没有解锁答案，也没有污染后续答卷。

修正脚手架后重新作答，并保留三条失败记录和其 281.260 s 消耗。汇总器会同时核验唯一成功
记录、所有候选摘要、冻结摘要、解锁摘要和阅卷摘要；不能通过覆盖失败记录来缩小用量。

## 正确性审计

独立阅卷按官方分值对 36 个小问逐项比较候选推导、最终表达式、数值、单位、符号和边界。
所有项目均为高置信度 `full-credit`。人工复查独立阅卷记录时重点检查了：

- T1-B2 的定义域与洛伦兹型分布；
- T1-B3 的离散覆盖条件和候选额外给出的整数修正；
- T3-B1、B2 的 1 nm 舍入差异；
- T3-D1 的倒易向量符号/排列等价性；
- T3-D3、D4 的深浅极小值、鞍点和最近邻坐标。

这些差异均不改变官方结论或得分。当前没有必须交给教师裁决的不确定项。

## 工程判断

这次测试支持两个结论：

1. 按官方小问天然形成原子任务，再在整题内保持共享状态，比让多个 Agent 自由反复质疑更
   稳定。三题各自一次有效求解，之后由隔离阅卷器逐小问验证，不需要无界认知环。
2. 用时与用量必须作为每个阶段的运行记录，而不是只记整批总量；系统失败也必须单列保留。
   但 provider 不报告 token 时，只能诚实标记不可得。若生产上必须精确比较求解 token，
   下一步应要求所有 solver adapter 统一回传 `input_tokens`、`output_tokens` 和
   `total_tokens`，不能从字符数反推。
