# F=ma 2024 Q14改写：可动圆环上的小珠

质量为 \(m\) 的小珠可在半径 \(R=0.20\,\mathrm m\) 的竖直光滑圆环上滑动。
圆环固定在质量也为 \(m\) 的支架上，支架可在光滑水平地面上移动。初始时小珠位于
圆环最低点，支架静止，小珠以 \(v_0=2.0\,\mathrm{m/s}\) 水平向右运动。运动到
某一时刻，小珠相对圆环瞬时静止。

1. 求该时刻小珠与支架的共同水平速度；
2. 求小珠上升的高度；
3. 求小珠沿圆环转过的圆心角。原题选项为
   A. \(30^\circ\)，B. \(45^\circ\)，C. \(60^\circ\)，
   D. \(90^\circ\)，E. \(120^\circ\)。

忽略一切摩擦，取 \(g=10\,\mathrm{m/s^2}\)。

> 来源：AAPT 2024 F=ma Exam Q14 的中文评测改写；官方答案为 C。
