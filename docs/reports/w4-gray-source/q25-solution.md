# 解析（学生版）

![悠悠球退绕半径变化示意图](assets/explanatory.svg)

## 答案速览

- （1）\(mgz=\frac12mv^2+\frac12I(v/r)^2\)；
- （2）\(v^2=2gz/[1+\ell/(2(\ell-z))]\)；
- （3）速度从零增大后又降为零，因此后段加速度必有向上分量，选 E。

## 一眼识别

- 最短主线：把变化的绕绳半径代入机械能，再用端点与连续性判断运动阶段。
- 随着退绕，更多能量进入转动，不能套用定轴半径不变的悠悠球结论。

## 详细解答

### 第 1 步：建立机械能关系

下降 \(z\) 时，重力势能减少量转化为平动和转动动能：

\[
mgz=\frac12mv^2+\frac12I\omega^2.
\]

代入 \(I=mR^2/2\)、\(\omega=v/r\)，得

\[
mgz=\frac12mv^2+\frac14mR^2\frac{v^2}{r^2}.
\]

### 第 2 步：代入退绕几何约束

由

\[
\frac{R^2}{r^2}=\frac{\ell}{\ell-z},
\]

整理机械能式：

\[
\boxed{
v^2=\frac{2gz}{1+\dfrac{\ell}{2(\ell-z)}}
}.
\]

当 \(z=0\) 时 \(v=0\)；当 \(z\to\ell\) 时，分母趋于无穷，\(v\to0\)。

### 第 3 步：判断加速度方向

释放后悠悠球先获得向下速度，因此中间阶段 \(v>0\)。但临近完全退绕时
\(v\to0\)。速度从零增大、又必须在下降过程中减小到零，所以后半段存在向上的
加速度；它不可能始终向下，更不可能始终保持某一种单调的向下加速度大小。

因此 A—D 均不正确，原题选

\[
\boxed{\mathrm E}.
\]

## 易错点

- \(r\) 随 \(z\) 改变，不能把 \(\omega=v/R\) 固定使用。
- 速度方向仍可向下，而加速度已经向上；不能混淆速度与加速度方向。
- 无需求出速度最大点的具体位置；端点与连续性已足以排除 A—D。
