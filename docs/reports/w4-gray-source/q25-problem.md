# F=ma 2024 Q25改写：变半径退绕的悠悠球

某悠悠球由两个均匀圆盘组成，总质量为 \(m\)、外半径为 \(R\)，转动惯量
\(I=mR^2/2\)。一根有厚度的轻绳在细轴上绕很多圈，绳的总长为 \(\ell\)；初始剩余
绕绳半径为 \(R\)。固定绳端后由静止释放悠悠球。下降距离为 \(z\) 时，剩余绕绳
半径 \(r\) 满足

\[
\frac{r^2}{R^2}=\frac{\ell-z}{\ell},
\]

且无滑动约束为 \(\omega=v/r\)。

1. 写出下降过程中的机械能关系；
2. 求平动速度 \(v\) 与 \(z\) 的关系；
3. 判断从释放到绳完全退绕的过程中，加速度是否始终竖直向下且大小恒定、递增或
   递减。请说明是否存在方向改变。原题选 E“以上均不正确”。

忽略能量损失，绳始终竖直。
