# F=ma 2024 Q13改写：斜绳双物块的瞬时张力

两个质量均为 \(m\) 的物块由不可伸长轻绳连接，绳跨过一个固定光滑轻滑轮。左物块
位于光滑水平面上；滑轮比水平面高 \(h\)，左物块与滑轮正下方的水平距离为 \(x\)；
右物块竖直悬空。两物块从静止释放，求释放后一瞬间的绳张力。

1. 建立左物块水平加速度、右物块竖直加速度之间的瞬时约束；
2. 求 \(T(x)\)；
3. 对所有可能的 \(x\ge0\)，给出 \(T\) 的范围，并核对 \(x=0\) 与
   \(x\to\infty\) 两个极限。原题正确图像选项为 B。

取重力加速度为 \(g\)，忽略一切摩擦。
