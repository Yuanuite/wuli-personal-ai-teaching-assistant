# 解析（学生版）

![斜绳双物块约束示意图](assets/explanatory.svg)

## 答案速览

- （1）若 \(s=\sqrt{h^2+x^2}\)，释放瞬间有 \(a_y=(x/s)a_x\)；
- （2）\(T=mg(h^2+x^2)/(h^2+2x^2)\)；
- （3）\(mg/2<T\le mg\)，且 \(T(0)=mg\)、\(T(\infty)=mg/2\)，原题选 B。

## 一眼识别

- 最短主线：几何约束给加速度投影，再分别对两物块列牛顿第二定律。
- 释放瞬间初速度为零，因此绳长二阶约束没有速度平方项。

## 详细解答

### 第 1 步：写出释放瞬间的绳长约束

斜绳段长度为 \(s=\sqrt{h^2+x^2}\)。左物块朝滑轮方向的水平加速度为
\(a_x\)，悬挂物块向下加速度为 \(a_y\)。释放瞬间速度均为零，对总绳长作二阶
变化关系可得

\[
a_y=\frac{x}{s}a_x.
\]

### 第 2 步：列动力学方程并求张力

左物块所受张力的水平分量提供加速度：

\[
ma_x=T\frac{x}{s}.
\]

右物块满足

\[
ma_y=mg-T.
\]

代入约束关系得

\[
g-\frac{T}{m}=\frac{x}{s}\frac{Tx}{ms}
=\frac{Tx^2}{m(h^2+x^2)}.
\]

所以

\[
\boxed{T=mg\frac{h^2+x^2}{h^2+2x^2}}.
\]

### 第 3 步：核对全范围与极限

\(x=0\) 时斜绳竖直，\(T=mg\)；当 \(x\to\infty\) 时，
\(T\to mg/2\)。对有限 \(x>0\)，分式严格位于 \(1/2\) 与 \(1\) 之间，
故

\[
\boxed{\frac{mg}{2}<T\le mg}.
\]

因此原题选 B。

## 易错点

- 不能直接令两物块加速度大小相等；斜绳长度变化只取水平加速度的投影。
- 一般时刻二阶约束含速度项，本题“释放后一瞬间”才可用上述简式。
- 极限值 \(mg/2\) 只在 \(x\to\infty\) 时趋近，有限 \(x\) 不取等号。
