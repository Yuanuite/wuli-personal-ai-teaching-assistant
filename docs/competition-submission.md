# 悟理

> 面向乡村课堂的端侧可信 AI 全流程教学助教平台

**项目口号：让 AI 成为每一位孩子持续生长的土壤。**

## 一句话介绍

教师上传学生错题后，悟理在本地组织 OCR、题干复核、分层解析、按需交互仿真、PDF/学生包交付和错题知识沉淀；教师把关关键结论，学生获得可离线阅读、可检索、可持续复习的个人学习资源。

## 项目定位

当前完整 MVP 聚焦高中物理，覆盖"端侧教研搭子"和"课后学习支持"，把两类能力串成同一条可审计流程：备课与课堂复盘 → 教师复核 → 课堂讲解 → 课后支持 → 资源沉淀。

## 为什么适合乡村课堂

- **弱网可用**：OCR 可在本机完成；PDF、Markdown、HTML 和 ZIP 交付后均可离线使用。
- **保护学生材料**：私有知识库与教师工作台默认在本机；发布学生站前必须裁剪或遮挡敏感信息并由教师确认。
- **降低教师门槛**：教师可直接说"处理现在新上传的题目"，也可在网页完成上传、复核、返修与下载。
- **减少重复劳动**：一次复核后的题目继续服务于课堂讲解、学生复习、变式训练和知识薄弱点分析。
- **不要求昂贵软件**：交互仿真是浏览器可直接打开的离线 HTML，不依赖专用仿真平台。

## 关键创新

1. **教师在回路中的可信工作流** — AI 负责提取、生成和检查候选结果，教师负责关键事实与教学结论。系统记录复核人、时间和内容摘要，使"谁确认了哪个版本"可以追溯。

2. **同题双层解析** — 学生版保留不超过五步的主线、易错点和快速自测；教师版补充符号、量纲、边界和完备性审计证据。

3. **答案与仿真共享物理真源** — 动态题使用同一个 `physics-model.json`，从源头减少"解析正确、动画错误"的分叉。

4. **交互仿真按需生成** — 所有题目保留可视化入口，但教师明确提出需求后仿真 Skill 才创建动态过程。

5. **私有教师端与公开学生端隔离** — 教师端保存原图和流程记录；学生端只接收白名单产物，静态站不连接教师端 API。

## 当前可验证成果

截至 2026-07-29，项目仓库中可直接核验：

- 23 道本地真实错题条目，均已 `delivered` 并进入本地学生站目录；
- 12 道题具有共享的结构化物理模型与交互仿真工作流；
- 30 条教师确认的固定检索评测；Hit@5 = 1.0000、Recall@5 = 0.8292、MRR = 0.8633；
- W3 自适应复杂题路由已通过 holdout（15/15）、灰度（9/9）和补充灰度（8/8），默认把复杂题路由到 W3；
- 385 项 Python 全量自动化测试通过；另有 4 条隔离 E2E 场景。

这些数字描述当前仓库状态，不代表已经完成学校规模化试点。

## 技术栈

| 层级 | 实现 |
|---|---|
| 生命周期总控 | Python 脚本与 `manage-student-error-library` Skill |
| OCR 与视觉复核 | Apple Vision 本地 OCR；可插拔视觉边车；教师人工兜底 |
| 教师端 | 本地 Web 工作台与 provider-neutral Agent Gateway |
| 正确性证据 | Claim Ledger、确定性证书、隔离语义复算、受控回跳 |
| 动态可视化 | `build-physics-simulator` Skill、Canvas/SVG、离线 HTML/ZIP |
| 学生端 | 纯静态只读站，可部署到 GitHub Pages |

## 边界与下一步

当前验证重点是高中物理单学生错题闭环。下一步优先验证真实乡村课堂中的教师时间节省、学生理解度和弱网设备兼容性，再扩展班级管理、跨平台 OCR 降级方案和其他学科模型。
