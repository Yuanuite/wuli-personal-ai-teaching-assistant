# 物理示意图质量提升：Flash 原子执行 Work-Tree

## 目标与边界

本轮不再调整 MiMo/DeepSeek 的职责：MiMo 继续只提供经教师复核的视觉事实，DeepSeek Flash 只在隔离任务中提出强类型 scene、渲染器和门控代码候选，Codex 审核后才能提升。流程图仍不是 fallback。

目标分成四项：轨迹几何可信、排版可读、核心概念助学、生产边界不回归。美观性不能仅靠单元测试证明，因此确定性检查和 PNG 人工审核必须同时存在。

## 执行线路

```text
A0 冻结基线
→ A1 Flash：几何合同
→ Codex 审核
→ A2 Flash：几何渲染
→ Codex 审核 + 单测
→ A3 Flash：标签避碰与纹理降噪
→ Codex 审核 + 布局指标
→ A4 Flash：周期/三维/阶段教学门控
→ Codex 物理语义审核
→ A5 全量回归
→ A6 两题隔离回放
→ A7 Codex 终审
```

A1–A4 串行执行，因为它们修改同一场景合同和渲染器；每一步只能读取上一版本已审核快照。Flash 不能批准自己的补丁，也不能把未通过的假设写入正式状态。

## 回跳规则

- 圆弧参数或 sweep 错误：只回跳 A1/A2；
- 文字碰撞、越界或场纹理过强：只回跳 A3；
- 周期、相位、三维方向或阶段表达不足：只回跳 A4；
- SVG 安全、默认流程图、Gateway 范围或全量测试回归：回跳最早引入问题的任务；
- 同一任务两次无改进即停止，保留 `provisional`，不继续消耗 Flash。

## 接受标准

V1 几何忠实性和 V4 生产安全必须全部通过。V2 排版或 V3 教学辅助若仍为 provisional，候选只能用于内部复核，不能升级为最终学生版教材图。机器可执行的完整任务、状态传递与验证账本见 `visual-diagram-quality-improvement-work-tree.v1.json`。
