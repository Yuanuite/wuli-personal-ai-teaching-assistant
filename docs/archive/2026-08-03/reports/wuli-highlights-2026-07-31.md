> 面向 5 分钟阅读：让别人快速理解"悟理是什么、强在哪、凭什么可信、怎么用"。

## 一、一句话

> **悟理不是又一个 AI 解题工具——它把一道学生错题，变成经过教师确认、可持续复用、可追溯正确性的教学资产。**

三个递进的卖点：

1. **全流程**——一次上传贯通备课、课堂、课后与教研沉淀；
2. **可信任**——教师复核门禁 + 版本摘要 + 确定性验证共同约束 AI；
3. **会生长**——错题、讲法、反馈与失败经验沉淀进本地知识库，为下一次处理提供证据。

## 二、核心亮点（有证据，不是自夸）

### 亮点 1：答案准确率——用 IPhO 真题闭卷验证过

- 2021 国际物理奥赛理论卷（T1/T2/T3）：**36/36 官方小问 full-credit、各 10/10 满分**；
- 求解器与阅卷器**隔离**：阅卷器只在候选冻结后才读官方解答；
- 独立 holdout **15/15**、生产灰度 **9/9**、官方竞赛补充灰度 **8/8**。

> **一句话**：不是模型觉得对，是独立阅卷器逐项核过。

### 亮点 2：答案可靠性——三层验证，投票不算数

- Agent 只能提交"候选"，晋升由**确定性复算 + 独立双模型验证 + 教师确认**三层决定；
- **禁止多数投票**——多数一致的错解比单次错解更有害；
- 14 类故障注入全部检出、错误晋升 0。

> **一句话**：模型多票一致 ≠ 正确；每一步可复核、可追溯。

### 亮点 3：解析可读性——学生版五步能懂，教师版完整可审计

- 学生版保留**不超过五步的主线**、易错点、30 秒自测，**禁积分/导数/超纲方法**（确定性扫描）；
- 教师版补充符号/量纲/边界/几何自洽/枚举完备性审计证据；
- 答案与仿真共享统一 `physics-model.json`，杜绝"解析说向左、动画却向右"。

> **一句话**：讲的人和学的人各取所需。

### 亮点 4：W3 解题 Loop——把"发散推理"变成"可终止、可审计的状态机"

投入心血最多、也最独特的部分：

- **DAG/环分离**：探索可以绕圈，证明图是 DAG——环永不改写证明；
- **义务发现门禁**：把"题目没说但必须验证的"显式化（量词/顺序/边界/分支/模型/适用域）；
- **投票不能决定真值**：晋升靠确定性证书复算，猜测永不晋升为正确；
- **影响锥回跳**：验证失败是定点外科手术，不是推倒重来；
- **硬熔断**：无进展/重复/预算上限 → 输出 `PROVISIONAL/UNRESOLVED`，绝不伪装成功；
- **工程收敛**：弹簧题从 190s → 68s（-64%），严谨做成可摊销的工程。

> **真实拦截案例**：IPhO 多流体静力题中，两个求解器共享同一套错误拆解、共同漏掉液面板段——被新增硬义务直接拒绝。

### 亮点 5：端侧可信 + 隐私 + 离线

- 服务默认只监听本机回环；**学生材料默认不出本机**，原始题图不上传云端；
- 本地 OCR + 离线 PDF/HTML/学生包，弱网可用；
- 公开题图裁剪遮挡 + 白名单发布，公开 ID 不可逆摘要。

> **一句话**：给答案的工具到处是，敢让学生材料留在本机的没几个。

### 亮点 6：评测纪律——不达标就明说（这是信任背书）

- 检索 Recall@5 = 0.8292 **未达 85% 门槛，就不宣称提升**；
- 成对评测发现 RAG 在难题退化 → **归因到证据包 → 精度门禁修掉**（恢复教师真值）；
- 7-31 CPhO 盲测整题正确 1/8 → **诚实记录，不改默认路由**（没把"可运行"当"可上线"）。

> **一句话**：我们公开自己最坏的结果，并据此自我修复——这就是可核验的诚实。

## 三、与通用 AI / 搜题 App / DeepTutor 的区别

| 维度 | 通用 AI / 搜题 | DeepTutor 类平台 | 悟理 |
|---|---|---|---|
| 给的 | 单次答案 | 学习平台功能 | **可复用教学资产** |
| 答案验证 | 模型自信 | 格式/渲染校验 | **确定性复算 + 独立验证 + 教师确认** |
| 方法合规 | 可能超纲 | 无 | **高中方法≤5步、禁超纲** |
| 教师角色 | 旁观者 | 可选 persona | **责任主体（四类门禁）** |
| 隐私 | 默认云端 | 默认联网 | **本地优先、学生材料不出本机** |
| 评测 | 无公开对照 | 无 eval 编排 | **成对评测 + 闭卷 + 独立 holdout + 诚实报告** |
| 可追溯 | 无 | 记忆可溯源但答案不可保证 | **"谁确认了哪个版本"全程可追溯** |

> 一句话：**DeepTutor 让 AI 更全面；悟理让 AI 更可信。** 广度是选择，可信是底线。

## 四、使用场景

### 乡村教师
- **痛点**：一人多角色、优质动态资源做不出、课后无法个性化、资源用完即散。
- **悟理给的**：拍照上传 → 本地 OCR → 题干复核 → 分层解析 → 按需仿真 → 离线投屏 → 学生包 → 知识沉淀。弱网可用、隐私本地、不要求昂贵软件。

### 家教/个人辅导
- **痛点**：错题会重犯、教辅不匹配个体、无持续追踪。
- **悟理给的**：每个学生的错题资产库 + 分层解析 + 变式训练 + 复习计划 + 薄弱点分析。

## 七、技术答辩：W3 解题 loop——最复杂，但也必要

> 若评委问"W3 是你设计中最复杂的地方？好在哪里？是否有必要？"，用下面这套应答。**核心策略：承认"最复杂"（9 倍行数），但把"复杂"重新定义为"对应问题难度的复杂度"，并承认它的真实价值是"可审计性"而非"更高的正确率"。**

### 7.1 主答辩（可直接背诵）

> "我直接承认：W3 是我设计里最复杂的部分，核心约 7,077 行，是普通解析的 9 倍。但我请求把'复杂'重新定义为对应问题难度的复杂度，而非炫技。
>
> 物理错题的六类真实失误——方向搞反、符号写错、边界漏取、多解漏根、首事件抓错、枚举不完备——**没有一类是算错，全是'该验证的没验证'**。通用模型单次生成无法自检，反复'重新想想'只会同一处跌倒。W3 就是把这种不可终止、不可审计的发散推理，工程化为可终止、可审计的状态机：DAG 与环分离、义务发现门禁、影响锥回跳、硬熔断。
>
> 我认为 agent 成熟的标志不是'能自主干活'，而是'能约束自己的自主性'——知道何时该停、何时承认不知道。W3 输出 PROVISIONAL、UNRESOLVED，正是用机器语言说'我不知道'。
>
> 这不是纸面设计。IPhO 多流体静力题中，两个独立 agent 共享同一套错误拆解、共同漏掉轻流体高出液面的板段——它们共同犯错、彼此印证，投票反而强化错误；最终是'自由液面/密度比'硬义务直接拦下。**自由 agent 的一致不等于正确，只有确定性义务能拦住共同错误。**
>
> 那 9 倍复杂度让简单题买单了吗？没有。所有题先过确定性初筛，高风险才进 W3，低风险走 W2——**复杂度按需分配**：简单题只付 W2 成本，复杂题才获得 W3 保障。失败即停，宁可输出'未解决'，不为'再试一次'追加成本。"

### 7.2 为什么"可审计性"是真正的价值（而非正确率）

> 9 倍复杂度买的不是"多拦截一道题"，而是**可审计性**：简单 verifier 拦下时你不知道它为何成功，漏掉时你不知道它为何失败；W3 的 DAG、义务发现、回跳锥让每一步"为什么"都可回放。**当失败发生时，W3 至少知道错在哪里——复杂度是让失败可解释的保险，不是炫技的成本。**

### 7.3 评委最可能的攻击与你的应对（对抗验证结论）

| 评委攻击 | 你的应对 |
|---|---|
| "IPhO 案例只是'自由液面/密度比'硬义务拦下的，200 行就够，7077 行是多 agent 编排的自嗨" | **部分承认**："硬义务确实拦下了那一题，这我认。但你要的是'一题拦下'还是'每题的义务都被发现'？义务发现本身正是 W3 在解决的——CPhO 1/8 恰恰说明它还没做好。可审计性是 9 倍复杂度买的东西，正确率是它还没证明的。" |
| "CPhO 1/8，按你的逻辑 W3 正以 7/8 制造错误认知" | **诚实认**："对，这正是我没粉饰的——1/8 说明它还不够好，所以我没改默认路由。但 1/8 也是'诚实记录'的证据：它至少知道错在哪一层，而不是假装全对。" |
| "PROVISIONAL 只是'重试预算+放弃'，通用 agent 平台标配" | **不硬顶**："行为上确实相似，但区别在'放弃之后'：通用 agent 放弃时你不知道它为什么放弃、放弃了什么；W3 把'为什么不可解'也写进审计账本。这是工程差异，不是修辞差异。" |
| "既然 90% 题走 W2，为什么默认不是 W3-only？" | **这是承认**："正是因为我们知道 9 倍复杂度不该浪费在简单题上——复杂度按需分配，就是对'复杂度应当配得上问题难度'的承认。" |

### 7.4 若被逼到墙角必须承认的三句话

1. **CPhO 1/8**：整题正确 1/8、教学批准 0/8，内容质量与 verifier 共同错误未达生产门槛，默认路由未改。
2. **无拦截基线**：没有生产拦截率数据、没有课堂实证——"防错"是待证假设，不是已验证收益。
3. **义务是败后补丁**：义务拦截是在特定题上补的、路由初筛是手写规则——都需随题型持续维护。

> **给作者的一句总结**：W3 不是解题更强的系统，而是更诚实的系统——用 9 倍复杂度，换来一句可信的"我不知道"。

## 附：最关键的诚实边界（被追问时）

1. **闭卷评测样本有限**：IPhO 36/36 是单份公开卷、样本小；"任意新题形式可证正确"未证明。
2. **Claim Evidence 是影子层**：断言级证书链已实现但默认关闭；说"能力存在"，不说"生产已启用"。
3. **教学效果无课堂实证**：结构证据充分，但"学生真的更懂"需真实试点；省时收益是估算、未实测。
4. **W3 内容正确率未达生产门槛**：CPhO 盲测整题正确 1/8、教学批准 0/8——结构故障已清零，内容质量与 verifier 共同错误是下一个战场；无生产拦截率基线。
5. **五步主线的教学有效性无课堂实证**：五步是"最短主线的上限"（比较至少两条可行路径后选最短），替代推导/边界讨论/完整验算放教师版——是结构合规保证，不是教学效果证明。
